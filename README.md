# Harsha Showroom

Build a premium cinematic automobile showroom website called HARSHA AUTOMOBILE SHOWROOM. Use a dark black/charcoal luxury visual system, ivory typography, subtle champagne-gold accents, glossy reflective showroom surfaces, large editorial type, generous negative space, and sophisticated motion. Create a full responsive homepage with: cinematic hero featuring a premium black production car; Featured Collection with luxury sedan, performance coupe, and luxury SUV; Categories (Luxury, Performance, SUV, Sedan, Electric, Executive); immersive featured vehicle section; Technology/Performance; Harsha × Automobile section; About Harsha; Test Drive CTA; cinematic footer. Use React/TypeScript/Tailwind. Use refined animations, subtle parallax, image/text reveals, premium hover interactions, and 2–3 strong WOW moments. Do not fabricate or substitute a human face for Harsha: reserve clearly named image slots for his real photo, which will be uploaded later. Make image assets easy to replace. No generic dealership template and no watermark-like branding in the site.
